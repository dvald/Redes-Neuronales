La misma neurona, sin framework y con Keras

A la izquierda, una neurona que aprende puertas lógicas de 3 entradas, escrita con NumPy. A la derecha, lo mismo en Keras. Cada concepto tiene el mismo color en los dos; pulsa uno para resaltarlo.

Sin framework: NumPy
import numpy as np

X = np.array([[0,0,0], [0,0,1], …, [1,1,1]])  # 8 filas
y = np.array([[0], [0], …, [1]])               # AND

weights = 2 * np.random.random((3, 1)) - 1
bias = 2 * np.random.random(1) - 1
epochs = 10000
learning_rate = 0.1

for epoch in range(epochs):
    output = sigmoid(np.dot(X, weights) + bias)
    error = y - output
    adjustment = np.dot(X.T, error * (output * (1 - output)))
    weights += adjustment * learning_rate
    bias += np.sum(error * (output * (1 - output))) \
            * learning_rate
15 líneasderivadas escritas a manobucle de épocas a mano
Con framework: Keras
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense
from tensorflow.keras.optimizers import SGD

model = Sequential([
    Dense(1, activation="sigmoid", input_shape=(3,))
])                                # crea pesos y sesgo
model.compile(optimizer=SGD(learning_rate=0.1),
              loss="mse")  # derivadas: automáticas
model.fit(X, y, epochs=10000, verbose=0)


# Los mismos X e y de la izquierda.
# fit() recorre las épocas, calcula el error,
# las derivadas y actualiza los pesos.
6 líneasderivadas automáticasépocas dentro de fit()
Idea clave: un framework no cambia las matemáticas de la neurona; te ahorra escribir a mano las derivadas, el bucle de entrenamiento y el código para la GPU.

    ¿Por qué TensorFlow usa grafos?
    
      
    Animaciones ilustrativas
    
      
    Tener el cálculo descrito como un grafo, y no como líneas de Python sueltas, permite cuatro cosas.
    
      
    
      
    
        
    1 · Eficiencia y optimización
    TensorFlow analiza el grafo, fusiona operaciones que se pueden combinar y elimina las redundantes.
    
        
    2 · Distribución del cálculo
    El grafo se divide en subgrafos que se ejecutan en distintos dispositivos o máquinas.
    
        
    3 · Persistencia y reutilización
    El grafo se guarda y se lleva a producción: para predecir no hace falta el código de entrenamiento.
    
        
    4 · Depuración estructurada
    Con el grafo a la vista se localiza dónde falla el flujo de datos, como unas formas que no encajan.
    
      
    
      
    Idea clave: un grafo es una descripción completa del cálculo: se puede optimizar, repartir, guardar e inspeccionar antes de ejecutarlo.

    Ventajas de Keras
    
      
    
        
    Sintaxis sencilla
    Un prototipo de red en unas pocas líneas.
    
        
    Rapidez para prototipar
    Probar una idea, cambiar capas y volver a entrenar es inmediato.
    
        
    Muchos tipos de red
    Densas, convolucionales, recurrentes… con la misma forma de trabajar.
    
        
    Escala a GPU y TPU
    El mismo código se ejecuta en GPU o TPU sin cambios.
    
      
    
      
    Idea clave: con Keras describimos la red (capas, activaciones, pérdida) y el framework se encarga del resto. Contar parámetros es sencillo: (entradas × neuronas) + neuronas en cada capa densa.
